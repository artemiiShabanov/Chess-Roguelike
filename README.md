# Chess-Roguelike

Шахматный рогалик: как Balatro, только шахматы. Убить все фигуры, а не короля, начиная с неполной доски

Godot 4.4. Проект Godot лежит в `chess-roguelike/`: открыть `chess-roguelike/project.godot` в редакторе, запуск F5.

- Дизайн: [docs/GDD.md](docs/GDD.md), решения в [docs/DESIGN.md](docs/DESIGN.md), спеки в [docs/specs/](docs/specs/)
